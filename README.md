# The Scholars BD — Alpha.HR Edition

A responsive, multi-page static website concept designed for GitHub Pages.

## Included pages
- `index.html` — Home
- `about.html` — About
- `courses.html` — Searchable and filterable program cards
- `admission.html` — Admission enquiry form (browser-local demo)
- `notices.html` — Notice board
- `gallery.html` — Gallery layout placeholders
- `contact.html` — Contact form (browser-local demo)
- `student-login.html` — Demo-only student sign-in
- `student-dashboard.html` — Demo student dashboard
- `404.html` — Not found page

## Features
- Responsive navigation and layouts
- CSS 3D hero artwork, floating animation and tilt cards
- Optional synthesized UI sound effects (starts OFF)
- Search/filter interactions on Programs
- Admission and contact forms saved to browser `localStorage`
- Demo student session using `sessionStorage`
- Footer credit: **Development & Modification by Alpha.HR**

## Publish on GitHub Pages
1. Extract this ZIP.
2. Create or open a GitHub repository.
3. Upload all files and folders from this project to the repository root.
4. In **Settings → Pages**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then Save.
6. Open the published Pages URL.

## Important before real-world use
The original reference website could not be fetched during creation, so this package is an independently designed approximation, not a verified page-for-page copy. Replace demo text, contacts, notices, gallery placeholders and program details with official content.

This is a static front-end. Form submissions are saved only in the visitor's browser; they are not emailed or sent to an admin. The student portal is a demo only and has no real authentication, database, payment, results, attendance or admin panel. A backend and secure authentication are required for those features.

Google Fonts are loaded from Google Fonts when internet is available. The rest of the site is self-contained.
